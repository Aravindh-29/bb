# Bachelor's Biryani — BB

Static website for GitHub Pages.

## Files
- `index.html` — complete website (CSS + JS embedded)
- `logo.webp` — BB logo
- `hero.webp` — biryani hero/product image
- `spices.webp` — spices image
- `chicken-fry.webp` — chicken fry image
- `mutton-fry.webp` — mutton fry image
- `plating.webp` — banana-leaf plating image

All image paths in `index.html` are relative to the repository root, so GitHub Pages can serve the site directly from the same repository.
